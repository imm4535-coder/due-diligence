# Security

Do not file confidential case contents or credentials in a public issue. Use GitHub's private vulnerability reporting if the maintainer has enabled it; otherwise report only a non-sensitive description and request a private channel.

Current release is local-first, with explicit unencrypted browser saves. It is not a secure data room, regulated processing service or immutable audit system. Do not use a shared browser profile for sensitive cases. Export only to trusted storage and review an AI provider's data policies before pasting case content.

Supported version: latest 0.1.x pilot release. No response-time SLA is promised.
