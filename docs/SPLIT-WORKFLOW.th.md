# Due Diligence Scanner + Investigator

สองปลั๊กอินแบบ skills-only ใช้แยกกันหรือทำต่อเนื่องในแชตที่เลือกทั้งคู่ได้ ตัวหนึ่งวางแผน อีกตัวตรวจหลักฐานตามแผน ชุดเดิม Due Diligence ยังอยู่ ไม่มีการลบข้อมูลหรือปลั๊กอินเดิม

สร้างและยืนยันว่าติดตั้งในบัญชีเจ้าของแล้ว:

- [Due Diligence Scanner](https://chatgpt.com/plugins/plugins_6ae43709c9c48191800ee4993bcbce2a)
- [Due Diligence Investigator](https://chatgpt.com/plugins/plugins_6ae4371d0f70819181de5a14ce2e4a16)

หากชื่อใหม่ยังไม่ปรากฏในแชตเดิม ให้เปิดแชตใหม่แล้วเลือกปลั๊กอิน ทั้งสองลิงก์เป็น private plugin ของเจ้าของบัญชี ไม่ได้เปิด public directory listing

## 1. เริ่มด้วย Scanner

เรียก `due-diligence-scanner` หรือใช้ชื่อ Due Diligence Scanner แล้วส่งโจทย์ เช่น:

> สแกนผู้ให้บริการ AI ที่เรากำลังจะจ้าง เพื่อวางแผนว่าต้องตรวจอะไรบ้างก่อนเริ่มงาน ยังไม่ต้องสืบค้นภายนอก ให้ระบุคำถาม สมมติฐาน หลักฐานที่ต้องหา ผลที่อาจพบ ผลต่อการตัดสินใจ ลำดับความสำคัญ งบ และจุดหยุด

จะได้แผนที่อ่านง่ายและแผน `dd-plan/1` ที่ส่งต่อได้ Scanner ใช้ข้อมูลที่ได้รับเพื่อวางแผน ไม่อ้างว่าข้อสงสัยเป็นข้อเท็จจริง และไม่เริ่มค้นภายนอกในคำสั่งสแกนอย่างเดียว

## 2. ส่งแผนให้ Investigator

เลือก Due Diligence Investigator และแนบ/วางแผนกับเอกสารที่อนุญาตให้ใช้:

> ใช้ due-diligence-investigator ตรวจตามแผนนี้ ภายในขอบเขตและงบที่กำหนด ส่งหลักฐาน ข้อขัดแย้ง ผลต่อการตัดสินใจ และประเด็นที่ต้องกลับมาปรับแผน

Investigator ใช้เอกสารและเครื่องมืออ่านข้อมูลที่มีอยู่จริงใน AI host นั้น ไม่มีการติดตั้ง search/registry API เพิ่ม ไม่มีการติดต่อบุคคล จ่ายเงิน หรือลงมติแทนผู้ใช้ ผลลัพธ์คือบันทึกที่ย้อนตรวจได้และ `dd-results/1`

## 3. ปรับแผนเมื่อหลักฐานเปลี่ยนคำถาม

ส่งผลลัพธ์พร้อมแผนเดิมกลับให้ Scanner จะคงรหัสงาน หลักฐาน และงบที่ใช้ไป เพิ่มเลข revision พร้อมบอกว่าการตรวจรอบใหม่มีโอกาสเปลี่ยนการตัดสินใจอย่างไร การส่งต่อข้ามแชตใช้การแนบหรือวาง JSON ด้วยตนเอง ไม่มีบริการส่งข้อความข้ามปลั๊กอินอัตโนมัติ

## ติดตั้งจาก ZIP

- ChatGPT: เปิดลิงก์ปลั๊กอินส่วนตัวที่ส่งให้ในแชต แล้วติดตั้ง/เลือกใช้ตามหน้าจอบัญชี หากแสดงในรายการสกิลแล้ว เรียกชื่อสกิลได้เลย ลิงก์ส่วนตัวไม่ใช่ public directory listing
- AI host ที่รองรับ skill ZIP: ใช้ไฟล์ `due-diligence-scanner-skill.zip` และ `due-diligence-investigator-skill.zip` ตามวิธี import ของ host
- Codex: แตก skill ZIP แล้ววางสองโฟลเดอร์ใน `~/.agents/skills/`
- Claude Code: วางสองโฟลเดอร์ใน `~/.claude/skills/`
- Agent Plugins 1.0: ใช้ plugin ZIP ของแต่ละตัวกับ host ที่รองรับแพ็กเกจรูปแบบนี้

ไม่มี Node/Python requirement สำหรับตัวสกิลเอง การรองรับไฟล์และการค้นขึ้นกับแพลตฟอร์ม ไม่ได้ทดสอบว่าติดตั้งได้กับ AI ทุกยี่ห้อ

## ตรวจรูปแบบการส่งต่อแบบ local

ถ้ามี Node.js 20+:

```
node scripts/review-plan.mjs examples/plan-example.json
node scripts/review-plan.mjs examples/plan-example.json examples/result-example.json
```

เพิ่ม path ผลรอบก่อนเป็น argument ที่สามเพื่อตรวจว่ารหัส งบ และหลักฐานก่อนหน้าไม่ถูกรีเซ็ต ตัวอย่างทั้งหมดเป็นข้อมูลสมมติ ไม่ใช่ผลตรวจบริษัทจริง

## ขอบเขตคุณภาพ

มีตัวตรวจโครงสร้าง ความสัมพันธ์รหัส ลำดับงาน งบที่รายงาน และสถานะหยุด/ตรวจต่อ พร้อมชุดทดสอบกรณีสำคัญ ตัวตรวจไม่สามารถยืนยันความจริงของเอกสารหรือความครบเชิงวิชาชีพ และไม่มีบริการ runtime บังคับงบค้น/เวลา สกิลกำหนดให้ host ติดตามและรายงานข้อจำกัดอย่างตรงไปตรงมา

ก่อนใช้กับงานผลกระทบสูง ต้องให้ผู้รับผิดชอบทบทวนขอบเขต หลักฐาน และข้อสรุปตามงานจริง ชุดนี้ไม่รับรองมาตรฐาน ISO/OECD/NIST และไม่อนุมัติธุรกรรมอัตโนมัติ
