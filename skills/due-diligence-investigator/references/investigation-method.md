# Bounded evidence investigation

Workflow: validate scope → select permitted task → obtain discriminating evidence → record provenance and counter-evidence → update hypotheses → assess changed action → stop or return a specific replan request.

Each observation ledger entry includes task ID, pass number, source/tool, access result, factual observation and uncertainty. Keep previous observations rather than rewriting history. Cite document pages/sections, not only a homepage URL. Inspect the content before citing it as read.

Use primary records where relevant and independent corroboration for material self-reports. Sources copied from the same origin share an independence group. A primary document can still be inauthentic, incomplete, stale or irrelevant. Evidence sufficiency depends on the claim; no universal “two sources proves it” rule applies.

Causal analysis distinguishes temporal order, a proposed mechanism, alternative explanations and confounding. Process tracing can test a mechanism; observational evidence may still leave causal uncertainty. Five Whys is a hypothesis-generation aid. Describe intervention points and their assumptions rather than promising one ultimate root cause.

Forecasting: define plausible external and managerial scenarios, the assumptions driving them, leading indicators and thresholds at which the preferred action changes. Use sensitivity analysis where numbers are supportable. Preserve the option to pilot, stage a commitment, add conditions or defer rather than pretending uncertainty is eliminated.

Research worth continuing has a stated decision benefit and an attainable evidence route. Repeated inaccessible searches, circular citations and new facts with no changed action are signals to stop/replan. Mandatory obligations remain subject to their verified basis, not an optional information-value ranking.

Reference foundations: [ISO 31000](https://www.iso.org/standard/31000), [IEC 31010](https://www.iso.org/standard/72140.html), [Magenta Book](https://www.gov.uk/government/publications/the-magenta-book), [Value of Information](https://arxiv.org/abs/1703.08994), [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework). These support the method; no standards certification or professional assurance opinion is claimed.
