# Due Diligence — พร้อมติดตั้ง

แตก ZIP ทั้งหมดก่อนเปิดไฟล์ ไม่ต้องใช้ GitHub ไม่ต้อง build และไม่ต้องมี API key

## ใช้ใน ChatGPT

เปิด https://chatgpt.com/plugins/plugins_6ae42b72e25c81918a3acc24636c17fb แล้วกด Install หากระบบแสดงว่าติดตั้งแล้ว ให้เริ่มแชตที่เลือกปลั๊กอิน Due Diligence ได้เลย

ลิงก์นี้เป็นปลั๊กอินส่วนตัวของเจ้าของบัญชี ยังไม่ใช่ลิงก์ติดตั้งสาธารณะสำหรับคนอื่น แจกชุด Skill ZIP แทนได้

ลองสั่ง: “ใช้ Due Diligence ตรวจเอกสารนี้ แยกข้อเท็จจริง ความเสี่ยง หลักฐานที่ยังขาด และสิ่งที่ต้องทำก่อนตัดสินใจ”

## เปิดแอปบนเครื่อง

- Windows: ดับเบิลคลิก `START-WINDOWS.bat`
- macOS: เปิด `START-MAC.command`
- Linux: รัน `sh START-LINUX.sh`

ตัวเปิดจะใช้ Node.js 20+ หรือ Python 3.10+ ที่มีอยู่แล้วบนเครื่อง หากไม่มีทั้งสองอย่าง ต้องติดตั้งอย่างใดอย่างหนึ่งก่อน ตัวแพ็กเกจไม่ได้แนบ runtime และไม่ติดตั้งโปรแกรมให้อัตโนมัติ

แอปจะเปิด http://127.0.0.1:4173 ให้เก็บหน้าต่างตัวเปิดไว้ระหว่างใช้งาน ปิดด้วย Ctrl+C หากเปิดหลายชุดให้ปิดชุดเดิมก่อน บน macOS หากระบบไม่อนุญาตให้เปิดสคริปต์ ให้ใช้ Terminal เข้าโฟลเดอร์นี้แล้วรัน `sh START-MAC.command` ไม่ต้องปิดระบบความปลอดภัยของเครื่อง

ข้อมูลแฟ้มบันทึกในเบราว์เซอร์เมื่อกดบันทึก ไม่ได้เข้ารหัสและไม่ได้บันทึกลงโฟลเดอร์แอป ส่งออก JSON เป็นสำรอง

## ติดตั้ง AI Skill

- Codex บน Windows: เปิด `INSTALL-CODEX-WINDOWS.bat`
- Claude Code บน Windows: เปิด `INSTALL-CLAUDE-WINDOWS.bat`
- macOS: เปิดไฟล์ `INSTALL-CODEX-MAC.command` หรือ `INSTALL-CLAUDE-MAC.command`
- Linux: `node install-skill.mjs codex` หรือ `node install-skill.mjs claude`

ตัวติดตั้ง Skill ต้องใช้ Node.js 20+ และจะไม่เขียนทับ Skill เดิม จากนั้น reload/restart AI host แล้วเรียก `due-diligence`

ถ้าไม่ใช้ตัวติดตั้ง ให้คัดลอกโฟลเดอร์ `skills/due-diligence` ไปที่ `~/.agents/skills/` สำหรับ Codex หรือ `~/.claude/skills/` สำหรับ Claude Code สำหรับ AI ที่มีเมนู Import Skill ให้ใช้ไฟล์ `due-diligence-skill.zip` ตามวิธีของแพลตฟอร์มนั้น การรองรับ ZIP แตกต่างกันตาม host

## เชื่อม MCP (ไม่จำเป็นสำหรับการใช้ Skill)

ใช้เครื่องมือ stdio MCP ที่ `src/mcp.mjs` กับ Node.js 20+ ต้องตั้งค่า absolute path ใน AI host ของคุณ ดูตัวอย่างใน `MCP-ตัวอย่าง.json` และแทนที่ `REPLACE_WITH_EXTRACTED_FOLDER` ก่อนใช้ ไม่ใช่ remote MCP server

## ถอนการติดตั้ง

ปิดตัวเปิดแอปแล้วลบโฟลเดอร์ที่แตก ZIP ลบ Skill เฉพาะโฟลเดอร์ `due-diligence` ที่ติดตั้ง หากจะลบข้อมูลแฟ้มด้วย ให้ส่งออก JSON ก่อน แล้วลบ site data ของ `http://127.0.0.1:4173` ในเบราว์เซอร์
